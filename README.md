# Fantasy Hub

Fantasy football league website for 4 NFL leagues. Built with React + Vite (frontend) and Express (backend), pulling live data from the Yahoo Fantasy API.

## Leagues
- Beaners & Husseins
- Rebirth
- Gentlemen's League
- Shoot the Shits

## Features
- Live standings and records
- Weekly matchup results with top scorers
- Full season schedule
- League rulebook per league
- Season history and past champions
- Social card studio for Instagram and Twitter

## Adding a 5th league
Edit shared/leagues.config.js and add a new entry. The site updates automatically.
